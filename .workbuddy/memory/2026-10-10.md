## 设计器右侧报价新增省份选择 → 预览到手价（含运费）

- 业主场景：「书法柜生成后客户发广州，想知道运费多少」；并明确接受「购物车里没地址数字变小、
  填地址后变回预览值」——**不改购物车**。
- 新纯模块 **`utils/designerLandedEstimate.ts`**：`estimateDesignerShipping(items, subtotal, province, user)`，
  镜像 `App.tsx` 购物车计费——型材 `PROFILE_WEIGHTS` + 海洋板 `MARINE_BOARD_WEIGHT_PER_SQM`
  （唯一来源 `utils/quickQuoteCatalog.ts`；App.tsx 还有一份本地副本没动）+ 配件 1kg 津贴
  `getAccessoryShippingWeightKg`（<¥30 且非 vip_plus）+ 首重/续重分档 + >1500mm 超长 +¥20
  （仅普通/顺丰，安能不计）+ 取最低档（等同购物车 `auto`）。省份列表 = `SHIPPING_RATES` 的键（31 个）。
  **空/未知省份返回 null**（面板只显示设计估价，和购物车没地址同形态）。省份只是 UI state，**不进设计文件/订单**。
- UI：右侧「设计估价」卡下加 `data-testid="diy-estimate-province"` 下拉 + 计费重量/预估运费/
  `diy-estimate-landed` 到手价；三语言新增 `estimateProvince/NoProvince/Weight/Fee/Landed/Hint`。
- 回归 **`npm run test:designer-shipping-estimate`**（已加进 `test:stool-all`）：凳子夹具发浙江必须
  落在已冻结的 **¥952**（11kg・安能 ¥33）；另断言超长、零重量、无/未知省份、新疆更贵。
  坑：脚本里 `const assert_ = assert` 会 TS2775（断言函数必须直接带类型），用原 `assert`。
- 冒烟（preview 4173）：示例工作台 设计估价 ¥670.4 → 广东 到手 ¥708.4（安能 ¥38，11kg）、
  新疆 ¥735.4。tsc 仍 9 个既有报错；build 过。
