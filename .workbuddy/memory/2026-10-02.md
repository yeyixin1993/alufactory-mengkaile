## 后台「每月收入」缺 10 月：UTC / 东八区归集口径 bug（已修）

- 现象：2026-10-02 后台统计「每月收入」只到 2026-09，没有 10 月。
- 排查：用 `.env` 里的 `ADMIN_OVERRIDE_PHONE/PASSWORD` 调 `POST /api/auth/login` 拿 token，
  再 `GET /api/admin/statistics` 与 `/api/admin/orders?per_page=200`（分 3 页共 543 单）核对。
- 根因：`app/routes/admin.py::_monthly_revenue_and_color_usage` 用
  `(paid_at or created_at).strftime('%Y-%m')` **按 UTC** 归月，但数据库存 UTC、
  后台所有界面按东八区渲染（`app/order_utils.py` 的 `to_east8_datetime`）。
  于是北京时间每月 1 日 00:00–08:00 付款的订单被算进上一个月。
  实测：`ORD202609301629427A1EB387`（北京 10-01 00:30 支付，¥160.80）被算进 9 月；
  更早一笔 `ORD20260331165530B3CA017E`（北京 04-01 00:55，¥852）被算进 3 月。
- 修复：
  - `admin.py` 改用 `to_east8_datetime(order.paid_at or order.created_at or datetime.utcnow())` 取 `%Y-%m`。
  - `app/routes/orders.py` 订单号生成的 `ORD` 时间戳也从 UTC 改成东八区，
    避免 10-01 的订单号显示成 `ORD20260930...`。
  - 新增回归 `tests/test_profile_inventory.py::test_monthly_revenue_buckets_by_beijing_calendar_month`。
- 修复后（用线上真实订单复算）：2026-09 = 19578.3，**2026-10 = 160.8**；
  3 月 9444.4→8592.4、4 月 8602.5→9454.5。
- 规则已写入 `docs/ORDER_RECORD_LIFECYCLE.md` 新增「时间口径（UTC 存储 / 东八区展示）」。
- 注：10-02 当天还有 2 张订单仍是 `pending`，按设计不计入收入（只统计 confirmed/shipped/delivered）。
- **代码只在本地，线上后台仍是旧逻辑，需要重新部署后端才会生效。**

## 设计器：打孔模式隐藏移动/长度手柄（已完成）

- 需求：客户进入「点选打孔」并选中某根型材时，移动型材的坐标手柄（含长度手柄）要临时隐藏，
  否则会挡住/抢走用来描述孔位的那次点击。
- 关键点（容易漏）：**three.js 的 raycast 不会跳过不可见对象**，
  所以只 `transform.detach()`（`_root.visible=false`）不够——
  `onPointerDown` 里直接对 `_gizmo.picker.translate.children` 做射线检测，仍会命中并启动一次拖动，
  把打孔那一下点击吃掉。必须同时屏蔽指针路径。
- 实现（`components/DIYDesigner.tsx`）：
  - 新增 `utils/designerDrillMode.ts::isMoveGizmoSuppressed(drillMode)`（唯一判定规则）。
  - gizmo 挂载条件加 `!suppressManipulators`；`syncProfileLengthHandles` 在打孔时传 undefined；
    同步 effect 的 deps 补 `drillMode`（原来没有，切换打孔不会重算）。
  - `onPointerDown` 的彩色轴选取加 `!isMoveGizmoSuppressed(drillModeRef.current)`；
    `onPointerMove` 的 hover 高亮同样跳过（否则光标会变 grab、`transform.axis` 被置位）。
  - 中/英/日 `drillModeHint` 补充说明「打孔期间手柄暂时隐藏，退出后恢复」。
- 校验：`scripts/verify-drill-mode-manipulators.ts` + `npm run test:drill-mode-manipulators`（通过）；
  `test:designer-group-move`、`test:calligraphy-opening` 回归通过；`tsc --noEmit` 无新增错误；`npm run build` 通过。
- 文档：`docs/DIY_DESIGNER_PROJECT_KNOWLEDGE.md` 第 10.1 节加第 6 条交互规则 + changelog 一条。
- 坑：`npm run build` 仍会被沙箱批量删除保护拦住，需要放行（非代码问题）。
