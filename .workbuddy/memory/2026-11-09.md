## 生产单 PDF 改为浏览器打印（方案 B，已实现）

- 预览页「下载 PDF」不再默认走 html2canvas，改为弹说明弹窗 → `window.print()`；新增「图片版 PDF」按钮保留位图兜底（手机/微信没有「另存为 PDF」）。原独立「打印」按钮保留（同一个 print，不弹说明）。
- 打印样式**内联注入在 `FactorySheetPreviewPage`**（`FACTORY_PRINT_CSS`），**不要**写进 index.css：画册页 `PrintableCatalog.css` 自带 `@media print` 满版契约（html/body/#root width 210mm、`.mkl-page` 297mm + break-after），全局 `@page` 会让画册每页溢出多出空白页。
- 打印 CSS 要点：`@page { size:A4; margin:8mm 0 }`（左右为 0，留白靠 FactorySheet 的 p-10，这样续页卡片不会被打印机裁切区切掉，且内容宽度不变 → 卡片不会变高）；`.factory-sheet` 打印时 `display:block` + `> * + * { margin-top:1.5rem }` 复刻 flex gap-6（Chrome flex 分页会忽略 break-inside:avoid）；`[data-pdf-block]/tr/img/svg` 全部 avoid；长表格 thead 用 table-header-group 重复。
- 孤页坑：一张卡片 1096px > 一页可用 1062px（297-16mm），会只溢出一行表格到下一页。解法 = 打印时 `.factory-card-body` 上下 padding 24→16px、`.factory-card-stack` 间距 32→16px（这两个类名加在 FactorySheet 的卡片正文上，只在 @media print 生效）。收紧后最大卡片 1048px，全部一页一张。
- 文件名：打印前把 `document.title` 临时改成单据号（Chrome/Edge 用它预填「另存为 PDF」文件名），`afterprint`/120s 兜底还原。
- 顺手修：结算存档 PDF 的 `orderRef` 不再是写死的 `"PREVIEW"`，`handleGeneratePDF(includePrice, returnBase64, orderRefOverride)` 传 `createdOrder.orderNumber || id`，手动下载时用随机 6 位单号；App.tsx 里的离屏 FactorySheet 用 `pdfOrderRef` state。
- 验证：headless Chrome + puppeteer-core（`/Users/eliye/node_modules/puppeteer-core`）用 `page.pdf({preferCSSPageSize:true, printBackground:true})` 打真实预览页（探针页临时渲染 `FactorySheetPreviewPage` 并预写 localStorage）。样例单（5 张加工卡 + 1 配件卡）出 7 页 A4（MediaBox 595×842）、每页文字都是真文本（BT 块 75-93）、无孤页、卡片不再被切断、编号白方块正常。**坑**：`workbuddy-pdf` 的 png 渲染会静默跳过第 7 页（该页有内容），最后用 `-f split` + `sips` 单独转才看到。探针文件已删。

## 编号方块「塌陷/字不居中」的真正原因（已修）

- 症状：图片版 PDF 里卡片编号（白方块+深数字）与孔面字母（深方块+白字母）的字压在方块底部并被裁切。
- **html2canvas 对「固定尺寸小方块内文字」的垂直居中整体失效**（基线贴底边），实测 flex/line-height/table-cell/grid/absolute inset 五种写法全失败，换字体（Arial/PingFang/默认）也一样；不是 flex-shrink 也不是设备/手机问题。
- 唯一可靠解：把字形放进内联 `<svg><text text-anchor="middle" dominant-baseline="central">`，html2canvas 会把它序列化成图片交给浏览器栅格化 → 完全居中。已在 `FactorySheet.tsx` 抽成 `SheetBadge({size,label,tone,fontSize})`，卡片编号 32px 白底、孔面字母 40px 深底，均带 `shrink-0`。
- 验证方法（可复用）：vite dev 起一个探针页渲染真实 `FactorySheet`（夹具：2 个 profile item，user 必须带 `addresses: []`，否则 `user?.addresses.find` 报错），再用 puppeteer-core 调页面里的 `html2canvas(el,{scale:2})` 取 dataURL，PIL 量方块 bbox 与字形 bbox 的四边留白。**注意**：`page.screenshot` 或 dev 浏览器里看着正常不代表图片版 PDF 正常，必须看 canvas 输出。
- 结果：编号方块 64×64、字形上下留白 17/18（2×）、左右 24/27；字母方块 80×80、四边留白均 26。
