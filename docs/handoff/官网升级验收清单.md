# 萌开了官网升级验收清单

验收人应在测试环境逐项确认。任何一项失败都不要发布正式站。

## A. 安装与基础兼容

- [ ] 使用干净环境安装依赖并完成前端正式构建。
- [ ] 后端 10 项现有测试全部通过。
- [ ] 首页、产品详情、登录、购物车、结算、订单和后台可以正常打开。
- [ ] 旧版商品、旧购物车、旧订单和旧 JSON 不需要补字段也能正常读取。
- [ ] 测试环境没有读取正式支付密钥或正式数据库。

## B. 来源信息全链路

- [ ] 使用 v2.43.1 插件导出一个测试 JSON。
- [ ] JSON 根级存在 `provenance`，并包含插件版本、模型名、唯一文档号和导出时间。
- [ ] 设计器导入后显示“SketchUp 萌开了插件”来源。
- [ ] 加入购物车后，购物项 `config.designSource` 完整保留。
- [ ] 创建订单后，订单 JSON 中仍能查看同一来源信息。
- [ ] 后台来源统计将该订单计入 SketchUp 插件来源。
- [ ] 未带来源的旧订单归类为“旧数据（来源未记录）”。
- [ ] 本地导入显示 `self_declared`，不得显示 `server_verified`。
- [ ] 同一设计只改变导出时间或文档号，仍能触发既有重复订单检查。

## C. 3.0 参数化展示架

- [ ] 产品页能够打开 3.0 参数化展示架并显示成品参考图。
- [ ] 修改宽、高、深、地柜高和上下层数时，预览及统计同步变化。
- [ ] 上部层板始终保持 20°斜装，不会变成平装。
- [ ] 下部每层生成一套完整抽屉和一套左右滑轨。
- [ ] 800×2000×450mm、地柜高 850mm、上 3 层、下 5 层可正常生成。
- [ ] 自动均分刚好达到 324.9mm 时不会误报间距不足。
- [ ] 自定义层板间距真正小于 324.9mm 时必须禁止生成。
- [ ] 超出参数范围的输入会被阻止，不会生成缩放后的固定五金。

## D. 构件、孔位和连接件

- [ ] 型材、板件、光轴、SK8、SHF8、抽屉滑轨和连接件在统计中分别出现。
- [ ] 每层光轴贯穿位置只有规则要求的真实孔，不出现支座孔重复叠加。
- [ ] 沉头通孔、端面攻丝和螺丝一一配对。
- [ ] 同一物理位置不存在重复角码或重叠连接件。
- [ ] 角码同时贴合两根对应型材，不悬空、不偏移、不穿模。
- [ ] 连接自检没有“0个直锁＋0个角码”或“一处多套连接”的异常。
- [ ] 新增但无官网 SKU 的构件显示为待补录，不会被型材替代。

## E. 发布与回退

- [ ] 网站主人确认正式库存、价格和新增构件 SKU。
- [ ] 发布前已备份前端、后端和生产数据库。
- [ ] Pull Request 中只包含预期源码，不包含 `.env`、数据库、账号、支付密钥或测试缓存。
- [ ] 已演练恢复旧构建包和旧后端版本。
- [ ] 正式发布后重复执行一次来源链路与下单冒烟测试。
